# BitCadence Platform v2 (proposal: low-fidelity screens)

Open `index.html` in a browser. These are static pages with no backend, and nothing here is built or approved.
They reuse `../redesign-v1/assets/style.css` and `app.js`, plus `assets/v2.css`.

Design, evidence and backlog:

- `docs/PLATFORM-V2-DESIGN.md`
- `docs/PLATFORM-V2-EVIDENCE.md`
- `docs/PLATFORM-V2-BACKLOG.md`

| File | What |
|---|---|
| `00-home.html` | "Needs you" first, then "Running now", with a status ladder on each card |
| `01-projects.html` | One project holding a coding, a media and an ops flow, plus "Start something new" from tested templates |
| `02-flow.html` | Step outline editor (not a canvas), "change it in words", reviewer rule, checks before Start |
| `03-run.html` | Previews, wait reasons, recovery cards (what happened, what's saved, what you can do) |
| `04-review.html` | Technical checks kept apart from taste, version compare, timecode comments, bounded fix, approval of one exact version |
| `05-library.html` | Characters & Voices, brand kits, and connections that show what each one may do |
| `06-operations.html` | Computers (model, role and host kept separate), helpers, queue reasons, GPU owner, spend, repairs |

The sample names, times and costs are made up for illustration. They are not fleet data.
Checked at 1280 px (light theme) and 390 px (dark theme): no horizontal page scroll and no script errors.
