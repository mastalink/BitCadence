Interface improvement status: U01–U24

Current status reviewed November 13, 2026 against the UX branch based on parent d511c6d. Implemented means source exists; fixture tested means isolated regressions cover the named behavior. Neither means the running app is updated, production work completed, or a deployment occurred. No live jobs, tokens, schedules, provider requests, worker handoffs or GPU operations were used for this review.

The GUI reference gives current instructions. Existing wiki URLs remain valid; older screenshots may show old labels. Source fingerprints are frozen and strictly verified. A disposable authenticated gateway passed 29 browser checks: all thirteen main destinations, Administration deep links and modal, Tab/Escape/focus return, 390px and 320px layouts and short-screen navigation, with no browser script errors. Broader desktop, assistive-technology and production end-to-end acceptance remains pending; individual limits below still apply.
