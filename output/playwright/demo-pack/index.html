Storage, requests and model usage can add cost. These estimates exclude tax and credits. The $25 tracking budget is not a spending cap; alert email setup is pending.

Know the boundaries

  • One availability zone and one hub: this is a test lab, not a highly available production service.
  • The encrypted data disk survives instance replacement. It is not a backup.
  • Workers cannot approve jobs. Only an authorized operator can release an approval-gated job.
  • Stopping jobs and stopping AWS machines are separate controls.
  • Evidence is locked for one day and scheduled to expire after seven days.
